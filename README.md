# Prompt Library 📚

A curated collection of reusable, well-structured prompts for enhancing AI interactions. This library provides a standardized approach to prompt engineering and management.

## 🎯 Features

- Pre-built, tested prompt templates
- Consistent formatting and structure
- Modular and reusable design
- Comprehensive documentation
- Version-controlled prompts

## 📁 Available Prompts

- 🧠 **Cognitive Mind Gym** - Personalized mental training program
- 🎓 **Interactive Expert Tutor** - Socratic-method learning assistant
- 🔧 **Software Project Requirements Engineer** - Systematic project planning
- ✨ **Expert Prompt Engineer** - Advanced prompt crafting specialist

## 🚀 Getting Started

Each prompt is stored in the `.github/prompts/reusable-prompts/` directory as a markdown file with proper front matter and structured content.

To use a prompt:

1. Navigate to the desired prompt file
2. Copy the content
3. Customize as needed for your use case
4. Follow the instructions within each prompt

## 📋 Prompt Structure

Each prompt follows a consistent structure:
```markdown
---
title: "Prompt Title"
description: "Brief description"
version: "1.0.0"
---

# Main Content
...
```
