# Model Prompt Templates

This folder contains 11 model-specific prompt templates covering Anthropic,
Google, and OpenAI model families.

- Use [user-guide.md](./user-guide.md) for model selection guidance.
- Use the individual model file when you need structure and examples tailored
  to a specific model.
- The latest OpenAI general-purpose template in this folder is
  [11-openai-gpt-5-4.md](./11-openai-gpt-5-4.md).
